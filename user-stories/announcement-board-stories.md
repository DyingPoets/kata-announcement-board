# Announcement Board — User Stories

**Source:** HR Manager + IT Admin interview
**Status:** Rough — needs refinement

---

## Story 1: Post Announcement
As an HR manager,
I want to post company announcements to a central board,
So that all employees see important updates in one place.

**Notes from interview:**
"Sometimes we need to flag something as urgent — like a building closure or a security alert. Those need to stand out visually and maybe send a notification."

---

## Story 2: Set Expiry
As an HR manager,
I want announcements to disappear automatically after a date I set,
So that the board doesn't fill up with old news.

**Notes:**
"We had an announcement from 18 months ago about a parking lot closure that was still showing. It's embarrassing."

---

## Story 3: Employee View
As an employee,
I want to see current announcements when I open the intranet,
So that I don't miss important company information.

**Notes:**
"Urgent ones should be at the top. Regular ones in date order. Expired ones just gone — employees shouldn't see them."
